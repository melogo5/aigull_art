# Архитектура SEO - Aigull Art

## 📊 Диаграмма потока данных

```
┌────────────────────────────────────────────────────────────┐
│                    Поисковая система                        │
│                  (Google, Yandex, etc.)                     │
└───────────────────┬────────────────────────────────────────┘
                    │
                    │ 1. Первый запрос
                    ▼
         ┌──────────────────────┐
         │  GET /robots.txt     │
         │  (Frontend - Nginx)  │
         └──────────┬───────────┘
                    │
                    │ 2. Ответ:
                    │    User-agent: *
                    │    Sitemap: /api/sitemap.xml
                    │
                    ▼
         ┌──────────────────────────┐
         │  GET /api/sitemap.xml    │
         │  (Backend - Express)     │
         └──────────┬───────────────┘
                    │
                    │ 3. Backend запрашивает данные
                    ▼
         ┌──────────────────────────┐
         │      MongoDB             │
         │  Collection: pictures    │
         └──────────┬───────────────┘
                    │
                    │ 4. Возвращает список картин
                    ▼
         ┌──────────────────────────┐
         │  Sitemap Controller      │
         │  генерирует XML          │
         └──────────┬───────────────┘
                    │
                    │ 5. XML с URL всех страниц
                    ▼
         ┌──────────────────────────┐
         │  <?xml version="1.0"?>   │
         │  <urlset>...</urlset>    │
         └──────────┬───────────────┘
                    │
                    │ 6. Поисковик индексирует
                    ▼
         ┌──────────────────────────┐
         │  Индекс поисковой        │
         │  системы обновлён ✓      │
         └──────────────────────────┘
```

## 🗂️ Структура файлов

```
aigull_art/
├── frontend/

│
├── backend/
│   └── src/
│       ├── controllers/
│       │   └── sitemapController.ts   ← Логика генерации sitemap
│       └── routes/
│           └── sitemapRoutes.ts       ← Маршрут /api/sitemap.xml

└── docs/

    └── SEO-ARCHITECTURE.md         ← Этот файл
```

## 🔄 Жизненный цикл обновления

```
┌─────────────────────────────────────────────────────────────┐
│  Администратор добавляет новую картину                      │
└─────────────┬───────────────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────────────────────────────┐
│  POST /api/pictures                                         │
│  { name: "Закат на Неве", year: 2024, ... }                │
└─────────────┬───────────────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────────────────────────────┐
│  MongoDB сохраняет картину                                  │
│  _id: 507f1f77bcf86cd799439011                             │
└─────────────┬───────────────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────────────────────────────┐
│  Sitemap автоматически обновляется при следующем запросе    │
│  (динамическая генерация из БД)                            │
└─────────────┬───────────────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────────────────────────────┐
│  Поисковик запрашивает /api/sitemap.xml                    │
│  и видит новую страницу:                                    │
│  /gallery/507f1f77bcf86cd799439011                         │
└─────────────┬───────────────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────────────────────────────┐
│  Новая картина появляется в Google/Yandex                   │
└─────────────────────────────────────────────────────────────┘
```

## 🎯 Приоритеты страниц

| Страница  | URL            | Priority | Change Freq | Обоснование           |
| --------- | -------------- | -------- | ----------- | --------------------- |
| Главная   | `/`            | 1.0      | weekly      | Самая важная страница |
| Галерея   | `/gallery`     | 0.9      | daily       | Часто обновляется     |
| Выставки  | `/exhibitions` | 0.9      | weekly      | Важный контент        |
| Биография | `/bio`         | 0.8      | monthly     | Редко меняется        |
| Контакты  | `/contacts`    | 0.7      | monthly     | Статичная информация  |
| Картина   | `/gallery/:id` | 0.8      | monthly     | Ценный контент        |

## 🚫 Что исключено из индексации

| Страница   | Причина                             |
| ---------- | ----------------------------------- |
| `/login`   | Техническая страница                |
| `/profile` | Приватная информация                |
| `/api/*`   | API endpoints, не для пользователей |

## 📈 Метрики успеха

После внедрения отслеживайте:

1. **Google Search Console**
   - Количество проиндексированных страниц
   - Количество показов в поиске
   - CTR (Click-Through Rate)

2. **Яндекс.Вебмастер**
   - Статус индексации
   - Количество страниц в индексе
   - Ошибки сканирования

3. **Аналитика**
   - Органический трафик
   - Поисковые запросы
   - Популярные страницы

## 🔧 Техническая реализация

### 1. robots.txt (статический)

```
Location: frontend/public/robots.txt
Served by: Vite dev server / Nginx
Type: Статический файл
```

### 2. sitemap.xml (динамический)

```
Endpoint: GET /api/sitemap.xml
Controller: backend/src/controllers/sitemapController.ts
Route: backend/src/routes/sitemapRoutes.ts
Database: MongoDB (collection: pictures)
Type: Динамическая генерация
Format: XML
```
