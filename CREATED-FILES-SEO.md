# 📦 Созданные файлы для SEO

## ✅ Основные файлы

### 1. `frontend/public/robots.txt`
**Назначение:** Управляет поведением поисковых роботов
- Разрешает индексацию публичных страниц
- Запрещает индексацию /login, /profile, /api/
- Указывает ссылку на sitemap.xml

### 2. `backend/src/controllers/sitemapController.ts`
**Назначение:** Логика генерации sitemap.xml
- Динамически создаёт XML из данных БД
- Включает статические и динамические страницы
- Использует актуальные даты обновления

### 3. `backend/src/routes/sitemapRoutes.ts`
**Назначение:** Маршрут для sitemap
- Обрабатывает GET /api/sitemap.xml
- Подключается к главному роутеру

## 🚀 Как использовать

### Локально
```bash
# 1. Запустить backend
cd backend
npm run dev

# 2. Проверить sitemap
curl http://localhost:5000/api/sitemap.xml

# 3. Запустить frontend
cd frontend
npm run dev

# 4. Проверить robots.txt
curl http://localhost:3000/robots.txt
```

### Production

1. Добавить в `.env`:
```env
FRONTEND_URL=https://aigull-art.com
```

2. Задеплоить проект

3. Зарегистрировать в:
   - Google Search Console
   - Яндекс.Вебмастер

4. Добавить sitemap:
```
https://aigull-art.com/api/sitemap.xml
```

|----------|-------|----------|
| `/robots.txt` | GET | Правила для роботов (статический) |
