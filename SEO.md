# SEO Оптимизация - Aigull Art

## 📋 Обзор

Проект настроен для оптимальной индексации поисковыми системами (Google, Yandex и др.).

## 🤖 robots.txt

### Расположение

`frontend/public/robots.txt`

### Доступ

`https://aigull-art.com/robots.txt`

### Что разрешено индексировать:

✅ Главная страница (`/`)
✅ Галерея (`/gallery`)
✅ Выставки (`/exhibitions`)
✅ Биография (`/bio`)
✅ Контакты (`/contacts`)

### Что запрещено:

❌ Страница входа (`/login`)
❌ Профиль (`/profile`)
❌ API endpoints (`/api/*`)

## 🗺️ sitemap.xml

### Расположение

Генерируется динамически на backend

### Эндпоинт

`GET /api/sitemap.xml`

### Доступ

`https://aigull-art.com/api/sitemap.xml`

### Структура

Sitemap автоматически включает:

1. **Статические страницы:**
   - `/` - Главная (приоритет 1.0, обновляется еженедельно)
   - `/gallery` - Галерея (приоритет 0.9, обновляется ежедневно)
   - `/exhibitions` - Выставки (приоритет 0.9, обновляется еженедельно)
   - `/bio` - Биография (приоритет 0.8, обновляется ежемесячно)
   - `/contacts` - Контакты (приоритет 0.7, обновляется ежемесячно)

2. **Динамические страницы:**
   - `/gallery/:id` - Каждая картина из базы данных (приоритет 0.8, обновляется ежемесячно)

### Особенности

- ✅ **Автоматическое обновление**: При добавлении новой картины в базу данных, она автоматически появится в sitemap
- ✅ **Актуальные даты**: Используются реальные даты последнего изменения из MongoDB
- ✅ **SEO-приоритеты**: Настроены приоритеты для оптимального ранжирования




### Валидация sitemap

1. Откройте [Google Search Console](https://search.google.com/search-console)
2. Добавьте ваш сайт
3. Перейдите в раздел "Sitemap"
4. Добавьте URL: `https://aigull-art.com/api/sitemap.xml`

## 📊 Регистрация в поисковых системах

### Google Search Console

1. Перейдите на [Google Search Console](https://search.google.com/search-console)
2. Добавьте сайт `https://aigull-art.com`
3. Подтвердите владение сайтом
4. Отправьте sitemap: `https://aigull-art.com/api/sitemap.xml`

### Яндекс.Вебмастер

1. Перейдите на [Яндекс.Вебмастер](https://webmaster.yandex.ru/)
2. Добавьте сайт `https://aigull-art.com`
3. Подтвердите владение
4. Отправьте sitemap: `https://aigull-art.com/api/sitemap.xml`

## 🔄 Принцип работы

```
┌─────────────────┐
│ Поисковый робот │
└────────┬────────┘
         │
         ├──► 1. Читает /robots.txt
         │      (узнаёт, что можно индексировать)
         │
         ├──► 2. Находит Sitemap в robots.txt
         │
         ├──► 3. Запрашивает /api/sitemap.xml
         │
         ├──► 4. Backend генерирует XML
         │      ├─ Читает статические страницы
         │      └─ Запрашивает картины из MongoDB
         │
         └──► 5. Индексирует все найденные страницы
```

## 📈 Ожидаемые результаты

После внедрения:

- 🔍 Сайт появится в поисковой выдаче Google/Yandex через 1-2 недели
- 🖼️ Каждая картина будет иметь свою страницу в поиске
- 📊 Улучшится видимость выставок и биографии художника
- 🚀 Ускорится индексация новых работ

## 🛠️ Техническая реализация

### Backend Controller

`backend/src/controllers/sitemapController.ts` - генерирует XML на лету

### Backend Route

`backend/src/routes/sitemapRoutes.ts` - обрабатывает запрос `/api/sitemap.xml`

### Frontend Static File

`frontend/public/robots.txt` - статический файл, раздаётся через Nginx/Vite

## 📝 Примечания

- robots.txt - это **рекомендация**, а не защита. Для реальной защиты используйте аутентификацию
- Sitemap может содержать до 50,000 URL (для больших сайтов нужно разделять на несколько файлов)
- Обновление индексации в Google может занять от нескольких дней до нескольких недель
